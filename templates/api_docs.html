Plant Pricing System API Documentation

Authentication: All API requests require a Bearer token in the Authorization header.
Example: Authorization: Bearer your_api_token

Quotations API

POST /api/v1/quotations

Create a new quotation with customer information and items.

Request Body

{
  "customer": {
    "name": "Acme Garden Center",
    "email": "info@acmegarden.com",
    "phone": "+1234567890",
    "address": "123 Garden Street, Plant City"
  },
  "items": [
    {
      "description": "Ficus Lyrata",
      "scientific_name": "Ficus lyrata",
      "pot_size": "17cm",
      "height": "80cm",
      "quantity": 5,
      "selling_price": 29.99,
      "vat_rate": 19.0
    },
    {
      "description": "Monstera Deliciosa",
      "scientific_name": "Monstera deliciosa",
      "pot_size": "21cm",
      "height": "100cm",
      "quantity": 3,
      "selling_price": 45.50,
      "vat_rate": 19.0
    }
  ],
  "currency": "€",
  "notes": "Special order for showroom display."
}

Response (201 Created)

{
  "status": "success",
  "quotation_id": 123,
  "quotation_number": "PAK-2025-042",
  "edit_url": "https://example.com/quotation/edit/123"
}

GET /api/v1/quotations

List all quotations, with optional filtering.

Query Parameters

  • customer_id (optional) - Filter by customer ID
  • limit (optional, default: 50) - Maximum number of results
  • offset (optional, default: 0) - Pagination offset

Response (200 OK)

{
  "status": "success",
  "count": 2,

API Testing

You can test the API using curl or any HTTP client. Here are some examples:

Create a new quotation

curl -X POST https://example.com/api/v1/quotations \
  -H "Authorization: Bearer your_api_token" \
  -H "Content-Type: application/json" \
  -d '{
    "customer": {"name":"Acme Garden Center","email":"info@acmegarden.com"},
    "items":[{"description":"Ficus Lyrata","quantity":5,"selling_price":29.99}],
    "currency":"€",
    "notes":"Test quotation"
  }'

Get a quotation

curl -H "Authorization: Bearer your_api_token" \
  https://example.com/api/v1/quotations/PAK-2025-042

List quotations

curl -H "Authorization: Bearer your_api_token" \
  https://example.com/api/v1/quotations?limit=10

Error Responses

The API returns standard HTTP status codes and JSON error responses:

{
  "status": "error",
  "message": "Error message describing the problem"
}

Common Error Codes

  • 400 Bad Request - Missing or invalid request parameters
  • 401 Unauthorized - Missing or invalid API token
  • 404 Not Found - Resource not found
  • 500 Internal Server Error - Server-side error
