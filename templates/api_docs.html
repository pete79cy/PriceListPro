Quotations

POST/api/v1/quotations 🔒 Auth required

Create a new quotation.

Request Body
{
  "customer": { "name": "Acme Garden", "email": "info@acme.com", "phone": "+357123456", "address": "Nicosia" },
  "items": [
    { "description": "Ficus Lyrata", "scientific_name": "Ficus lyrata", "pot_size": "17cm", "height": "80cm", "quantity": 5, "selling_price": 29.99, "vat_rate": 19.0 }
  ],
  "currency": "€",
  "notes": "Showroom display",
  "valid_until": "2026-04-30",
  "status": "DRAFT"
}
Response (201)
{ "status": "success", "quotation_id": 123, "quotation_number": "PAK-2026-042", "edit_url": "/quotations/123" }

GET/api/v1/quotations 🔒 Auth required

List all quotations.

Query Parameters
  • customer_id — filter by customer
  • status — filter by status (DRAFT, SENT, ACCEPTED, REJECTED, COMPLETED)
  • limit (default: 50), offset (default: 0)
curl -H "Authorization: Bearer YOUR_TOKEN" \
  "https://yourapp.replit.app/api/v1/quotations?status=SENT&limit=20"

GET/api/v1/quotations/{quotation_number} 🔒 Auth required

Get a specific quotation by number (e.g. PAK-2026-001). Returns full details including items, supplier info, and size options.

curl -H "Authorization: Bearer YOUR_TOKEN" \
  "https://yourapp.replit.app/api/v1/quotations/PAK-2026-001"

Customers

GET/api/v1/customers 🔒 Auth required

List all customers.

Query Parameters
  • search — search by name, email, or phone
  • category_id — filter by category
  • limit (default: 100), offset (default: 0)
curl -H "Authorization: Bearer YOUR_TOKEN" \
  "https://yourapp.replit.app/api/v1/customers?search=garden"

GET/api/v1/customers/{id} 🔒 Auth required

Get a specific customer including their contacts, quotations summary, and orders summary.

curl -H "Authorization: Bearer YOUR_TOKEN" \
  "https://yourapp.replit.app/api/v1/customers/5"

Suppliers

GET/api/v1/suppliers 🔒 Auth required

List all suppliers.

Query Parameters
  • search — search by name, contact person, or email
  • is_inhouse — true or false
  • limit (default: 100), offset (default: 0)

GET/api/v1/suppliers/{id} 🔒 Auth required

Get a specific supplier with their full product list.

GET/api/v1/suppliers/{id}/products 🔒 Auth required

List all products from a specific supplier.

Query Parameters
  • search — filter by product name
  • limit (default: 200), offset (default: 0)

Orders

GET/api/v1/orders 🔒 Auth required

List all orders with financial totals.

Query Parameters
  • status — filter by status (new, confirmed, processing, completed, cancelled)
  • customer_id — filter by customer
  • limit (default: 50), offset (default: 0)
curl -H "Authorization: Bearer YOUR_TOKEN" \
  "https://yourapp.replit.app/api/v1/orders?status=new"

GET/api/v1/orders/{order_number} 🔒 Auth required

Get a specific order with all items and computed totals (subtotal, VAT, discount, total).

curl -H "Authorization: Bearer YOUR_TOKEN" \
  "https://yourapp.replit.app/api/v1/orders/ORD-2026-001"

Invoices

GET/api/v1/invoices 🔒 Auth required

List all invoices.

Query Parameters
  • customer_id — filter by customer
  • limit (default: 50), offset (default: 0)

GET/api/v1/invoices/{invoice_number} 🔒 Auth required

Get a specific invoice with all line items.

Price Lists

GET/api/v1/price-lists 🔒 Auth required

List price list entries (customer-specific product prices).

Query Parameters
  • customer_id — filter by customer
  • product_id — filter by product
  • limit (default: 100), offset (default: 0)

Products

GET/api/v1/products

Search products. No authentication required.

Query Parameters
  • search — search by name, category, SKU, or scientific name
  • limit (default: 50)
curl "https://yourapp.replit.app/api/v1/products?search=ficus"

GET/api/v1/products/{id} 🔒 Auth required

Get full details for a specific product.

Company Settings

GET/api/v1/company-settings 🔒 Auth required

Get company information (name, address, contact details).

Response
{
  "status": "success",
  "name": "My Plant Company",
  "address_line1": "123 Green Street",
  "address_line2": "Nicosia, Cyprus",
  "phone": "+357 22 123456",
  "email": "info@myplants.com",
  "pdf_orientation": "portrait"
}

Error Responses

{ "status": "error", "message": "Description of the problem" }
  • 400 — Bad request (missing or invalid parameters)
  • 401 — Unauthorized (missing or invalid API token)
  • 404 — Resource not found
  • 500 — Server error
