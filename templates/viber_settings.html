Viber Integration Settings

Configuration

This page allows you to configure the integration between your Plant Pricing System and Viber. With this integration, you can receive updates to supplier product information directly from Viber groups.

How it works

The Viber integration lets suppliers update their product information by sending messages in a specific format to their Viber groups that you monitor.

Message format example: Product: Plant name, Scientific name: Latin name, Size: 20cm, Pot: 17cm, Price: €10.50

When a supplier sends a message in this format, the system will automatically update the corresponding product in your database or create a new one if it doesn't exist.
