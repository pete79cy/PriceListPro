Viber Integration Documentation

This documentation provides instructions on how to integrate your supplier's Viber groups with the system to automatically update product information.

Overview

The Viber integration allows you to automatically update supplier product information based on messages posted in their Viber groups. When suppliers post product information in their Viber groups, our system can extract this information and update the database accordingly.

Setup Process

1. Create a Viber Bot

  1. Create a Viber account if you don't already have one
  2. Visit the Viber Developer Console
  3. Create a new bot with the following information:
    • Name: Your company's name
    • Avatar: Your company logo
    • Account type: Business
    • Category: Utilities & Tools
  4. After creating the bot, you'll receive an authentication token

2. Configure the Integration

  1. Go to the Viber Settings page
  2. Enter your Viber bot's authentication token
  3. Set the webhook URL to: {{ request.url_root }}viber/webhook
  4. Click "Save Settings"

3. Map Viber Groups to Suppliers

  1. Invite your bot to the Viber groups where suppliers post product information
  2. Go to the Viber Settings page
  3. In the "Supplier Mapping" section, select a supplier and enter the Viber group's ID
  4. Click "Add Mapping"
  5. Repeat for each supplier group
Note: To get a Viber group's ID, you can use the "Test Webhook" feature on the Viber Settings page. Send a test message to the group and check the logs to find the conversation ID.

Message Format

For the system to properly extract product information, suppliers should format their messages in a specific way. The system can recognize various formats, but using a consistent format will ensure the most accurate data extraction.

Recommended Format

Product: [Product Name]
Scientific Name: [Latin Name]
Height: [Height in cm]
Pot: [Pot size in cm]
Price: €[Price]

Example:

Product: ΛΑΝΤΑΝΑ
Scientific Name: Lantana camara
Height: 30cm
Pot: 17cm
Price: €4.50

Alternative Formats

The system can also extract information from less structured messages, such as:

ΚΥΚΑΣ ΡΕΒΟΛΟΥΤΑ 40cm σε γλάστρα 14cm, τιμή €8.50

Or:

Νέα παραλαβή: ΔΙΕΦΕΝΜΠΑΧΙΑ (Dieffenbachia amoena), ύψος 30-35cm, γλάστρα 15cm, €5.20
Note: The more structured the message, the more accurate the extraction will be.

Data Processing

Update Logic
  • New Products: If a product doesn't exist for the supplier, a new product will be created with all the information provided.
  • Existing Products: If a product already exists, its information (price, pot size, height, etc.) will be updated with the new values.
Matching Criteria

Products are matched based on their name and supplier. If a product with the same name already exists for a supplier, it will be updated rather than creating a new one.

Troubleshooting

  1. Verify that the webhook URL is correctly set
  2. Check that the bot is a member of the group
  3. Ensure the group ID is correctly mapped to the supplier
  4. Verify the message format follows the guidelines
  5. Check the application logs for any errors

  1. The message may be using a format the system can't fully interpret
  2. Try using the recommended message format
  3. Check that all required information is included in the message
  4. Look at the system logs to see what information was extracted

  2. Verify that the correct group ID is linked to the right supplier
