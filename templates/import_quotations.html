Excel Spreadsheet Format

For Excel imports, your file should have the following columns:

  • Product Name/Description - Required
  • Quantity - Required
  • Price - Required (unit price)
  • Scientific Name - Optional
  • Pot Size - Optional
  • Height - Optional
  • Supplier - Optional
JSON Format

For JSON imports, use files exported from the "Export Quotations" feature.
