You're hitting a PostgreSQL SSL connection closed unexpectedly error:

(psycopg2.OperationalError) SSL connection has been closed unexpectedly

This is not a SQL syntax error, but a database connectivity issue.
✅ Likely Causes

    Database connection dropped unexpectedly

        Server restart

        Network blip

        Long-lived connection killed by DB server

    Connection pool exhausted (too many sessions)

    SSL misconfig (less likely if it usually works)

✅ Immediate Fix (Code Side)

Make sure SQLAlchemy connections are:

    pooled properly

    disposed on failure

Add a reconnect wrapper using engine.dispose() on failure.

Example:

from sqlalchemy.exc import OperationalError

try:
    result = db.session.execute(...)
except OperationalError as e:
    db.engine.dispose()
    flash("Database connection reset. Please try again.", "danger")

✅ Recommended: Configure SQLAlchemy Engine

When creating engine/session:

from sqlalchemy import create_engine
from sqlalchemy.pool import QueuePool

engine = create_engine(
    'your-db-url',
    poolclass=QueuePool,
    pool_size=10,
    max_overflow=20,
    pool_timeout=30,
    pool_recycle=1800  # close idle connections
)

Also apply in app.config['SQLALCHEMY_ENGINE_OPTIONS'].
✅ Final Checks

    Check your PostgreSQL logs (timeouts, crashes, or SSL disconnects).

    Monitor connections: SELECT * FROM pg_stat_activity;

    Ensure PostgreSQL max_connections is not exceeded.
