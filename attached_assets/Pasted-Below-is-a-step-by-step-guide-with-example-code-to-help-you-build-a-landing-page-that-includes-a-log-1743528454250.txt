## 2. Create the Basic Flask App

**File: app.py**

This script sets up the Flask server with routes for the landing page, login processing, and the price list manager page.

```python
from flask import Flask, render_template, request, redirect, url_for, session, flash

app = Flask(__name__)
app.secret_key = 'your_secret_key'  # Replace with a secure random key for production

# Sample credentials for demonstration. In production, manage users securely.
users = {
    'admin': 'password123'
}

@app.route('/')
def index():
    return render_template('index.html')

@app.route('/login', methods=['POST'])
def login():
    username = request.form.get('username')
    password = request.form.get('password')
    if username in users and users[username] == password:
        session['user'] = username
        return redirect(url_for('price_list'))
    else:
        flash('Invalid credentials, please try again.')
        return redirect(url_for('index'))

@app.route('/price-list')
def price_list():
    if 'user' not in session:
        return redirect(url_for('index'))
    return render_template('price_list.html')

@app.route('/logout')
def logout():
    session.pop('user', None)
    return redirect(url_for('index'))

if __name__ == '__main__':
    app.run(debug=True)
```

**Explanation:**  
- The landing page (`/`) shows the login form.  
- The `/login` route processes credentials and, on success, redirects the user to the price list manager.  
- The `/price-list` route displays the price list manager (accessible only to logged-in users).  
- The `/logout` route lets users log out.

## 3. Create HTML Templates

### Landing Page with Login

**File: templates/index.html**

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>Business Tools Landing Page</title>
  <link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
</head>
<body>
  <h1>Welcome to My Business Tools</h1>
  <form action="{{ url_for('login') }}" method="post">
    <div>
      <label for="username">Username:</label>
      <input type="text" name="username" id="username" required>
    </div>
    <div>
      <label for="password">Password:</label>
      <input type="password" name="password" id="password" required>
    </div>
    <div>
      <button type="submit">Login</button>
    </div>
  </form>
  <!-- Future: Add more buttons/links for additional business tools -->
</body>
</html>
```

## 5. Testing and Future Expansion

- **Run the Application:**  
  On Replit, run your Flask app. Open the webview to see your landing page. Try logging in with the sample credentials (`admin` / `password123`).

- **Future Tools:**  
  - To add more features, create additional routes and templates (e.g., `/tool2`, `/tool3`) and update the landing page with links or buttons to access these tools.
