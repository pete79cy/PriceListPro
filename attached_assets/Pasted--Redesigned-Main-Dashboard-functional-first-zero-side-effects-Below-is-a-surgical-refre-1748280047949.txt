### Why this structure?

| Original pain-point                            | Change                                                     | Benefit                           |
| ---------------------------------------------- | ---------------------------------------------------------- | --------------------------------- |
| Grid of six large cards required scrolling.    | Compress to **summary bar + 2-column “working zone.”**     | Key stats visible without scroll. |
| Mixed-priority information (counts vs. links). | Split into *Numeric summary* (counts) vs. *Action panels*. | Clear visual hierarchy.           |
| Secondary tools buried far down the page.      | “Quick Actions” tall card (left column).                   | Faster muscle-memory access.      |
| Analytics chart tiny, low contrast.            | Dedicated right-column card, larger canvas.                | Readable trends at a glance.      |
| System info mixed with tools.                  | Status card anchored bottom-left of grid.                  | Ops data grouped, easier scan.    |

## 2. Detailed component spec

| Component              | Spec                                                                                                                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Top Nav**            | *Add* `+ New` primary button with dropdown (Quotation, Order, Customer). Replace scattered upload/search buttons with a universal **⌘ K / Ctrl K command palette** icon.                 |
| **Summary Mini-Cards** | 3 cards (Customers, Quotations, Orders)  – 128 × 96 px, dark surface `bg-[#2b2e33]`, subtle inset shadow, metric in **32 px Semibold**, label 12 px Medium. Cards clickable entire area. |
| **Quick Actions**      | Vertical list, each row = icon (24 px) + label. Hover = `bg-[#3a3d42]`, active = brand blue. Primary/secondary color tokens inherited from existing theme.                               |
| **Analytics**          | 100 % width bar chart, `height: 220px`, 6 statuses. Use your existing JS chart lib; add tooltip on hover with absolute value + pct share.                                                |
| **System Status**      | Table-style list: ✔ Database (Connected), 🔄 Version, ⏰ Last Login. Use accent pill (`Connected`, `Offline`) right-aligned.                                                              |
| **Docs / Help**        | Light-tone surface to distinguish from dark UI. Include single “View Docs” button + small caption “Need help? Ask the assistant”.                                                        |

---

## 3. Visual polish guidelines

1. **Color contrast** Cards `#26292d`, page background `#1c1e22` → WCAG AA on text.
2. **Spacing scale** Use 8-pt grid: mini-cards `gap-4`, grid columns `gap-6`.
3. **Radius** Unify at `0.5 rem` (8 px) — nav button, cards, pills.
4. **Motion** 0.18 s ease-out for card hover elevate (`translate-y-1 scale-[1.01]`).
5. **Typography** Inter / SF Pro; weights 600 for headings, 500 for labels, 400 body.

---

## 4. Responsive breakpoints

| Width                  | Behaviour                                                                                    |
| ---------------------- | -------------------------------------------------------------------------------------------- |
| `≥ 1024 px` (desktop)  | 2-column grid as shown.                                                                      |
| `768-1023 px` (tablet) | Collapse to **single column**, Quick Actions becomes horizontal scroll list.                 |
| `< 768 px` (mobile)    | Summary mini-cards snap to 2-up grid, analytics collapses into swipe-carousel, footer hides. |
