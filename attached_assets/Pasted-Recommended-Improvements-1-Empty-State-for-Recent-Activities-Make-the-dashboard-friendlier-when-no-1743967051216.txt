Change card color based on value thresholds:

    Low customer count → warning

    High avg order value → success

Server-side example:

card_classes = {
    "customers": "bg-info" if stats.customers > 50 else "bg-warning",
    ...
}

3. Auto-Submit Filter

Use JavaScript to auto-submit the form on filter change:

document.getElementById("customer-category-filter").addEventListener("change", function () {
    document.getElementById("search-form").submit();
});

Allow sorting by:

Add to form:

<div class="col-md-3">

        <option value="recent" {% if sort == 'recent' %}selected{% endif %}>Most Recent</option>
