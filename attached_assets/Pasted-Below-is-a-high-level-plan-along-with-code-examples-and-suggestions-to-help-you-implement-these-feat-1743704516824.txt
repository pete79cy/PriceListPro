## 2. Supplier Database and Tracking

### a. Supplier Model

Create a new table to store supplier information and the products associated with them:

```python
class Supplier(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(255), unique=True)
    products = db.relationship('SupplierProduct', backref='supplier', lazy=True)

class SupplierProduct(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    supplier_id = db.Column(db.Integer, db.ForeignKey('supplier.id'))
    product_name = db.Column(db.String(255))
    height = db.Column(db.String(50))
    price = db.Column(db.Float)
    last_detected = db.Column(db.DateTime)
```

### b. Updating Supplier Data

Whenever a quotation is processed, update or insert supplier product data:

```python
def update_supplier_product(supplier_name, product_name, height, price):
    supplier = Supplier.query.filter_by(name=supplier_name).first()
    if not supplier:
        supplier = Supplier(name=supplier_name)
        db.session.add(supplier)
        db.session.flush()
    
    supplier_product = SupplierProduct.query.filter_by(
        supplier_id=supplier.id, product_name=product_name).first()
    
    if supplier_product:
        supplier_product.height = height
        supplier_product.price = price
        supplier_product.last_detected = datetime.utcnow()
    else:
        supplier_product = SupplierProduct(
            supplier_id=supplier.id,
            product_name=product_name,
            height=height,
            price=price,
            last_detected=datetime.utcnow()
        )
        db.session.add(supplier_product)
    db.session.commit()
```

Call this function during your quotation processing loop.

## 4. Supplier Data Search Functionality

- **Backend Search:**  
  Create a search route to query the SupplierProduct table based on keywords (e.g., product name, supplier name). For example:

```python
@app.route('/supplier/search')
def supplier_search():
    query = request.args.get('q', '')
    results = SupplierProduct.query.filter(
        SupplierProduct.product_name.ilike(f"%{query}%")
    ).all()
    return render_template('supplier_search.html', products=results)
```

- **Frontend Search:**  
  Provide a search bar that submits the query and displays the matching supplier products. You can then drag these results into your report builder.
