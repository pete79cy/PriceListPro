“Quotations” — task-first mobile layout

Below is a redesign that keeps every action reachable with one thumb-tap, makes the list scannable at a glance, and collapses the bulky filter panel into an unobtrusive sheet.

2 Key usability gains

Issue today	New behaviour
Full-width “Customize PDF” button clutters top area.	Move to kebab menu inside each quote card (“Download → Custom fields”).
Filter panel consumes ¾ of first screen.	Collapsed into slide-up sheet triggered by tiny filter icon on search row.
Action buttons cramped (eye / pdf / bin).	24 px touch targets, spaced 8 px; long-press card = context menu.
Hard to scan status vs date.	Badges inline: ● Sent • 27 May—same baseline, small separator dot.
New quote button buried under filter block.	＋ New in top bar—always visible, iOS “Compose” pattern.

4 Interaction details
	•	Pull-to-refresh on the quotes list (mobile convention) instead of top-right reload icon.
	•	Long-press a card to enter multi-select mode (✓ overlay) then bulk actions appear in bottom bar (Delete, Export CSV).
	•	When user hits ＋ New from mobile, open in full-screen modal; on desktop, side-by-side drawer.
	•	FAB “Insights” can stay bottom-right but reduce to 48 px circle instead of pill to save space.

⸻

5 Implementation order
	1.	Replace filter panel markup with hidden <div id="filterSheet">.
	2.	Move ＋ New button into top bar and wire route.
	3.	Wrap list rows with new card component; reuse existing status colors.
	4.	Add small JS (Alpine/vanilla) for sheet toggle and bulk-select.
	5.	Progressive enhancement: if JS disabled, fallback is current desktop layout.
