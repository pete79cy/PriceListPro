## 3. Surgical fixes (no backend changes)

| Area                        | Patch                                                                                                                                                                              |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Sub-header**              | Combine title, count-pill, search and **+ New** into one flex container (height ≈ 48 px).                                                                                          |
| **Remove grey boxes**       | Use cards only for two things: filters rail, table wrapper. Convert headings (“Quick Filters”, “Bulk Actions”) to `sr-only` for accessibility; visual labels become compact pills. |
| **Filter & category chips** | Inline pills (`inline-flex items-center gap-1 rounded-full bg-[#32363b] px-3 py-1 text-xs`) – no big blocks.                                                                       |
| **Bulk action bar**         | Hidden by default; `translate-y-[-100%] opacity-0` until at least one checkbox ticked → slide-down. Dark translucent background (`bg-black/30 backdrop-blur-sm`).                  |
| **Table density**           | Row class: `whitespace-nowrap py-3 px-4 hover:bg-[#303338]`. Header weight `font-semibold`. Add dashed column divider between “Category” and “Activity” for easier scan.           |
| **Action menu**             | Replace outline rectangles with a floating popover: `absolute right-6 top-2 rounded-md bg-[#2b2e33] shadow-lg ring-1 ring-black/50`. Anchor arrow (`::before`) to kebab.           |
| **Typography**              | H1 → dropped to `text-xl font-semibold`; everything else `sm` / `xs` with 500 weight.                                                                                              |
