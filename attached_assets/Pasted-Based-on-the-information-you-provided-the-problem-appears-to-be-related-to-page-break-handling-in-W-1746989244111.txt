### 3. Table Size Control with Programmatic Logic

```python
def adjust_table_rows_for_pagination(products):
    """
    Adjusts the product list for better pagination.
    Divides products into pages with a specific number of products per page.
    """
    # Calculate how many products fit on the first page (e.g., 7)
    first_page_items = 7
    
    # Calculate how many products fit on subsequent pages (e.g., 8)
    other_pages_items = 8
    
    # Organize products into pages
    paginated_products = []
    
    # First page
    if len(products) > 0:
        paginated_products.append({
            'page': 1,
            'products': products[:first_page_items]
        })
    
    # Subsequent pages
    remaining_products = products[first_page_items:]
    page_num = 2
    
    while remaining_products:
        page_products = remaining_products[:other_pages_items]
        paginated_products.append({
            'page': page_num,
            'products': page_products
        })
        remaining_products = remaining_products[other_pages_items:]
        page_num += 1
    
    return paginated_products
```

### Additional Tips for WeasyPrint:

1. **Update WeasyPrint to the latest version**: Newer versions have better support for page break control.

3. **Adjust @page margins**: Make sure you have enough space for the footer with appropriate margins in @page.

4. **Debug with weasyprint.logger**: Enable logging to identify potential issues with page breaks.

6. **Test with different paper sizes**: Sometimes slightly adjusting the paper size can help resolve layout issues.
