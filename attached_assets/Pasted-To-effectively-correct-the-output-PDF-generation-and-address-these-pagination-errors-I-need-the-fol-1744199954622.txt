        Header and footer structure (content, height).

    Format: This template definition could be in various forms:
        A separate template file (e.g., HTML, CSS, or a specific reporting format).

2.  Dynamic Content Handling Rules:

    Data: I need the logic that governs how data is inserted into the report. This is crucial for pagination.
        Table row splitting logic: Rules for how rows are split when they exceed the page height.

        Handling of long text fields: Rules for wrapping or truncating text within cells.
    Format: This logic could be expressed as:
        Code (e.g., functions or algorithms).
        Configuration settings.
        Rules defined in a templating language.

3.  PDF Generation Library/Tool Details:

    Data: Information about the library or tool used to generate the PDFs. Different tools have different capabilities and limitations that affect how pagination is handled.
        Name and version of the library/tool.
        Its pagination features and settings.
        Any known bugs or limitations related to table rendering.
    Importance: This helps in identifying if the issue is due to the library itself or how it's being used.

4.  Debugging and Testing Capabilities:

    Functionality: I need ways to debug and test the PDF generation process effectively.
        Detailed logging: To trace the layout process and identify where page breaks are occurring.

5.  Control over PDF Generation Parameters:

    Access: I need the ability to control specific parameters of the PDF generation process.
