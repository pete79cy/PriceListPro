## 🎯 Most Common Cause (based on previous errors)

### ❌ The column `updated_price_list` exists in your model, but not in the DB.

If you're adding an `OrderItem` with:

```python
updated_price_list = Column(Boolean, default=False)
```

But this column doesn’t exist in the database schema, **it will crash during `.commit()` or `.flush()`**.

---

## ✅ Fix Option A – Add the Column

Run this SQL manually (if you want to keep this logic):

```sql
ALTER TABLE order_item ADD COLUMN updated_price_list BOOLEAN DEFAULT FALSE;
```

Then restart:

```bash
python app.py
```

---

## ✅ Fix Option B – Remove it from the model

If you don’t need `updated_price_list`, go to `models.py`, find the `OrderItem` class, and:

```python

```

Comment it out or delete it.

Then:

```bash
python app.py
```

## 💡 Bonus Tip: Protect `/add_item` from crash

Wrap your `db.session.commit()` in a try-except to catch failures and return a user-friendly message.

```python
try:
    db.session.commit()
except Exception as e:
    db.session.rollback()
    flash("Error adding item: " + str(e), "danger")
```
