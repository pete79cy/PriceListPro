### Quick wins you can push today

1. **Uniqueness & race-free order numbers**

   ```python
   order_number = db.Column(db.String(20), unique=True, index=True, nullable=False)
   ```

2. **Decimal money helper**

   ```python
   from decimal import Decimal
   def to_decimal(x): return Decimal(str(x)) if x is not None else None
   ```

   Then:

   ```python
   item.price  = to_decimal(unit_price)
   item.vat_rate = to_decimal(vat_rate)
   ```

3. **Route sanity check**

   ```bash
   flask routes | grep '/orders'
   ```

   Confirm no duplicates.

4. **Error logging decorator**

   ```python
   def log_exceptions(fn):
       @wraps(fn)
       def wrapper(*a, **k):
           try:
               return fn(*a, **k)
           except Exception:
               current_app.logger.exception(f"Error in {fn.__name__}")
               db.session.rollback()
               raise
       return wrapper
   ```

   Apply to noisy handlers like `update_item_inline`.
