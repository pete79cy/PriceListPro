### Why the chips don’t respond — and three tiny fixes to make them work

Right now the **filter / category buttons** are plain `<button>` elements without any JavaScript or hyperlink attached, so the browser has no idea what to do when they’re clicked.
You have two simple implementation paths—pick whichever matches how the rest of your app already works.

| Path                                        | When to use                                                                         | How it works                                                                                                                                         |
| ------------------------------------------- | ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Server-side refresh (query-string)**   | Your page is rendered by Flask/Jinja and you’re okay with a full reload.            | Each chip is just an `<a href="?filter=missing_email">`. Flask reads `request.args["filter"]`, runs the proper query, and re-renders the table.      |
| **2. Client-side filter (JS/Alpine/React)** | You already ship JavaScript on this page and want an instant, no-reload experience. | Rows carry `data-category`, `data-has-pricelist` etc. Chips toggle a variable in JS; you show/hide rows with `display:none` or a React state filter. |

Below are minimal snippets for **both** approaches—drop in whichever matches your stack.

---

## 1. Server-side GET parameter (Flask)

### Jinja template

```html
<aside class="w-56 space-y-4">
  <a href="{{ url_for('customers', filter='all') }}"
     class="chip {{ 'active' if current_filter == 'all' }}">All {{ total }}</a>

  <a href="{{ url_for('customers', filter='price_lists') }}"
     class="chip {{ 'active' if current_filter == 'price_lists' }}">With Price Lists {{ with_price }}</a>

  <a href="{{ url_for('customers', filter='missing_email') }}"
     class="chip {{ 'active' if current_filter == 'missing_email' }}">Missing Email {{ missing_email }}</a>
</aside>
```

### Flask view

```python
@app.route("/customers")
def customers():
    f = request.args.get("filter", "all")
    q = db.select(Customer)
    if f == "price_lists":
        q = q.where(Customer.price_lists.any())
    elif f == "missing_email":
        q = q.where(or_(Customer.email == None, Customer.email == ""))
    customers = db.session.execute(q).scalars()
    return render_template("customers.html",
                           customers=customers,
                           current_filter=f,
                           total=db.count(Customer.id),
                           with_price=db.count(Customer.price_lists.any()),
                           missing_email=db.count(or_(Customer.email == None, Customer.email == "")))
```

**Bonus:** because the link is a normal `<a>`, users can bookmark or share the view.

## 2. Instant client-side filter (Vanilla JS)

### Mark up each row with data attributes

```html
<tbody id="custBody">
  {% for c in customers %}
  <tr
      data-price="{{ 'yes' if c.price_lists|length else 'no' }}"
      data-email="{{ 'yes' if c.email else 'no' }}"
      class="row">
    …
  </tr>
  {% endfor %}
</tbody>
```

### Tiny JS (inline or separate file)

```html
<script>
const chips = document.querySelectorAll('[data-chip]');
const rows  = document.querySelectorAll('#custBody .row');

chips.forEach(chip => chip.addEventListener('click', e => {
  chips.forEach(c => c.classList.remove('active'));
  e.currentTarget.classList.add('active');

  const mode = e.currentTarget.dataset.chip;   // all | price | missing
  rows.forEach(r => {
    if (mode === 'all')       r.hidden = false;
    else if (mode === 'price')   r.hidden = r.dataset.price !== 'yes';
    else if (mode === 'missing') r.hidden = r.dataset.email !== 'no';
  });
}));
</script>
```

### Chip HTML

```html
<button data-chip="all"      class="chip active">All {{ total }}</button>
<button data-chip="price"    class="chip">With Price Lists {{ with_price }}</button>
<button data-chip="missing"  class="chip">Missing Email {{ missing_email }}</button>
```

No build tools, no frameworks—just native JS.
If you’re using **Alpine.js** the same can be one-liner: `x-show`, `@click="$store.filter='price'…"`.

## 3. Styling reminder

```css
.chip {
  @apply inline-flex items-center gap-1 rounded-full bg-[#32363b] px-3 py-1 text-xs text-gray-200
         hover:bg-[#3a3d42] transition;
}
.chip.active {
  @apply bg-blue-600 text-white;
}
```

> **Tip:** keep the `cursor:pointer` and `user-select:none` so they feel like real buttons.
