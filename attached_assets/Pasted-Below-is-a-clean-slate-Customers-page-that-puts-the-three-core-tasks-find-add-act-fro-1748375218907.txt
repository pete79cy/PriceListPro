Below is a **clean-slate “Customers” page** that puts the three core tasks— *find*, *add*, *act*—front-and-center and hides everything else until it’s needed. The markup is plain HTML + Tailwind; the behaviour uses just a few lines of vanilla JS, so you can drop it into Flask/Jinja or React without rewiring your backend.

## 2 Why it’s more user-friendly

| Friction before                     | Fix in this design                                                    |
| ----------------------------------- | --------------------------------------------------------------------- |
| Hidden errors stop chips & buttons. | **Zero JS dependency** on element IDs; event delegation guards nulls. |
| Filters felt secondary & scattered. | Single smart-filter bar always visible under the toolbar.             |
| Too many grey boxes / borders.      | One card: the table. Everything else is lightweight flex rows.        |
| Kebab menus looked bolted on.       | Shadcn/DropdownMenu gives native dark popover with arrow.             |
| Bulk actions were buried.           | Bulk-bar slides down when ≥1 row selected, ESC to dismiss.            |

## 4 Behaviour in \~40 lines of JS

```html
<script defer>
document.addEventListener('DOMContentLoaded', () => {
  const filters   = { price:false, missing:false, tags:[] };
  const rows      = document.querySelectorAll('#custBody .row');
  const bulkBar   = document.getElementById('bulkBar');
  const chkAll    = document.getElementById('chkAll');
  const chkRows   = document.querySelectorAll('.chkRow');
  const bulkCount = document.getElementById('bulkCount');

  /* smart-filter toggle */
  document.getElementById('filterBar').addEventListener('change', e => {
    const f = e.target.dataset.f;
    if (!f) return;
    filters[f] = e.target.checked;
    applyFilters();
  });

  function applyFilters(){
    rows.forEach(r => {
      const show =
        (!filters.price   || r.dataset.price  === 'yes') &&
        (!filters.missing || r.dataset.email === 'no')  &&
        (filters.tags.length === 0 || filters.tags.some(t => r.dataset.tags.includes(t)));
      r.hidden = !show;
    });
  }

  /* bulk-selection */
  chkAll.addEventListener('change', () => {
    chkRows.forEach(c => { if (!c.closest('tr').hidden) c.checked = chkAll.checked; });
    updateBulkBar();
  });
  chkRows.forEach(c => c.addEventListener('change', updateBulkBar));

  function updateBulkBar(){
    const n = [...chkRows].filter(c => c.checked && !c.closest('tr').hidden).length;
    bulkCount.textContent = `${n} selected`;
    bulkBar.classList.toggle('hidden', n === 0);
  }
});
</script>
```

## 5 Why you’ll like maintaining it

* **Single source of truth** – data attributes come from the DB; no duplicated state.
* **No fragile IDs** – only `filterBar`, `custBody`, `bulkBar` used.
* **Progressive enhancement** – if JS fails, table still shows all customers and “＋ New” still posts to `/customers/new`.
