### Customers module — surgical redesign (same design language as the refined dashboard)

I’ll keep the DB/API exactly as-is and only touch markup/CSS/React props, so nothing breaks downstream.
Below is a drop-in layout plan plus the small Tailwind (or Bootstrap) utilities you need.

## 2. UI details & micro-interactions

| Element                | Spec                                                                                                                                                                                                      |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Sub-header**         | `flex items-center justify-between py-3 px-4 bg-[#2b2e33] rounded-md mb-6`<br>Left: **Customers**  `text-lg font-semibold`  + small count pill.<br>Right: `<input class="w-60">` + **+New** split-button. |
| **Quick Filters rail** | `hidden lg:block` (`flex-none w-60 mr-6`) inside a `rounded-md bg-surface p-4 space-y-2`. Each filter row: checkbox + label + count badge.                                                                |
| **Table wrapper**      | `relative overflow-x-auto rounded-md bg-surface shadow-card`<br>`table-auto w-full text-sm`                                                                                                               |
| **Sticky header**      | `thead th sticky top-0 bg-surface z-10` + darker bottom border.                                                                                                                                           |
| **Row hover**          | `hover:bg-[#32363b] cursor-pointer transition-colors`                                                                                                                                                     |
| **Action buttons**     | Combine **Edit** & **Delete** into a *kebab (⋮)* menu per row to cut visual noise (iOS Human-Interface-Guidelines: “reduce chrome”).                                                                      |
| **Bulk toolbar**       | Appears when one or more rows selected; slides down from top of table: `transform translate-y-[-100%]` → `translate-y-0`. Contains *Export CSV*, *Delete*, *Send email*.                                  |
| **Pagination**         | `page-size 20` by default; numbers + «prev/next» centred under table. On ≥1024 px screens show “Rows 1-20 of 44”. Mobile: infinite scroll.                                                                |

## 4. Accessibility & performance touches

* **Keyboard nav** – `tabindex="0"` on each row; **Enter** opens detail drawer.
* **ARIA live** region announces “4 rows selected” when bulk-select checkboxes toggle.
* **Virtualisation** (optional) – if dataset may explode to >2 k rows, plug in `react-window` while keeping sticky header.
* **Debounced search** 250 ms to avoid hammering DB.
