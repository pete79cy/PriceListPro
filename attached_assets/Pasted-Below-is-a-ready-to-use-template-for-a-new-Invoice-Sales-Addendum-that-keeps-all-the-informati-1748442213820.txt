### ❶ Key usability tweaks

| Before                                                  | Now                                                                         |
| ------------------------------------------------------- | --------------------------------------------------------------------------- |
| Greek header sat on its own line ⇒ takes vertical room. | English & Greek titles share space (primary/secondary).                     |
| Document meta in list format.                           | Two-column “information cards” so client & invoice data scan in one glance. |
| Wide table with eight headings felt heavy.              | Compact, zebra-striped rows; numeric columns right-aligned.                 |
| Totals mixed inside main table.                         | Totals boxed in `<tfoot>` with bold right alignment.                        |
| Status line buried.                                     | Bold “Draft / Paid” chip inside details card—always visible.                |

### ❷ How to turn this into PDF

1. **WeasyPrint** (Python)

   ```python
   from weasyprint import HTML  
   HTML("addendum.html").write_pdf("addendum.pdf")
   ```
2. **wkhtmltopdf** (CLI)
   `wkhtmltopdf addendum.html addendum.pdf`
3. Any browser → *Print → Save as PDF* (the CSS uses standard units & looks good at A4).

### ❸ Where to drop your data

* Replace sample rows inside `<tbody>` via Jinja, React, or your preferred template engine.
* Fill meta fields (`invoice_no`, `period_from`, …) server-side.
* Attach a QR/Barcode in the header if you use eArchiving—there’s white space next to the logo.
