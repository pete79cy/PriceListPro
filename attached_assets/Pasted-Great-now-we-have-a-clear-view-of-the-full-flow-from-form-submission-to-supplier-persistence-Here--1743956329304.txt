### ✅ Updated Flask Route (Refactored & Safer)

```python
# routes/supplier_routes.py

from flask import request, redirect, url_for, flash
from flask_login import login_required
from sqlalchemy.exc import SQLAlchemyError
from app import db
from models import Supplier
from utils.supplier_utils import get_supplier_by_name_or_create


@app.route('/add_supplier', methods=['POST'])
@login_required
def add_supplier():
    """Endpoint to add a new supplier or retrieve existing"""
    name = request.form.get('name', '').strip()

    if not name:
        flash('Supplier name is required.', 'danger')
        return redirect(url_for('suppliers'))

    try:
        supplier = get_supplier_by_name_or_create(name)
        if supplier:
            if supplier.created_at == supplier.updated_at:
                flash(f'Supplier "{supplier.name}" created successfully.', 'success')
            else:
                flash(f'Supplier "{supplier.name}" already exists.', 'info')
        else:
            flash('Failed to add supplier.', 'danger')

    except SQLAlchemyError as e:
        db.session.rollback()
        flash('Database error while adding supplier.', 'danger')
        app.logger.error(f"Error creating supplier: {e}")

    return redirect(url_for('suppliers'))
```

This version adds:
- Input sanitation
- Exception handling with rollback
- Specific feedback (created vs. existed)
